# Installation - SPEC-3

## Prerequisites

- VS Code or Cursor.
- GitHub Copilot enabled.
- Basic understanding of REST APIs.

No server execution is required. This is a document and code analysis exercise.

## Setup

1. Open the `repo/` folder.
2. Read `repo/spec.md` and `repo/app.py`.
3. Create `repo/alignment-report.md`.
4. Create `repo/spec-v2.md` if the specification needs corrections.

## Verification

The exercise is complete when the alignment report and improved specification are available.
